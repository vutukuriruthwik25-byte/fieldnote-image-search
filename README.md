Fieldnote is a visual search app for finding images by place, mood, or subject. It searches Wikimedia Commons and presents image finds in a responsive grid, with loading, empty, and error feedback. The page uses an editorial field-guide layout with a forest-and-sand palette to make browsing feel calm and tactile. Descriptive search chips help visitors get started, while a framed empty state makes the waiting area feel intentional.
